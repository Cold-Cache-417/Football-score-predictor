# Data Contract — La Liga Football Score Predictor

Every file the website / API layer consumes, what columns mean, and what each
probability means. Goal: consume artefacts **without refitting**.

## Exported artefacts

| file | format | content |
|---|---|---|
| `data/website/test_predictions.csv` | CSV, one row per test match | Keys (`season, date, home, away, result, odds_source`) + per-model H/D/A columns + bookmaker de-vigged probs/odds + true result |
| `data/website/test_scorelines.parquet` | Parquet, one row per test match | Keys + `h_gf`, `a_gf`, `grid` (flat list of 225 floats, row-major: index = home_goals × 15 + away_goals) |

Per-model H/D/A columns in `test_predictions.csv` (order H, D, A):

| column | meaning |
|---|---|
| `book_p_h/d/a` | de-vigged bookmaker probabilities; `odds_h/d/a` raw decimal odds + `odds_source` |
| `dc_p_h/d/a` | Dixon-Coles (time decay, xi = 0.001) refit per matchweek |
| `cat_p_h/d/a` | CatBoost (tuned: depth 4, lr 0.05) refit per matchweek |
| `xgb_p_h/d/a` | XGBoost (tuned: depth 4, lr 0.05) refit per matchweek |
| `blend_p_h/d/a` | blend: `w * CatBoost + (1 − w) * DC`, `w = 0.35` |
| `base_p_h/d/a` | historical base rates |

## Probability semantics

- H/D/A are `P(home win) / P(draw) / P(away win)` in outcome order [H, D, A]
  (`result` codes: 0 = home win, 1 = draw, 2 = away win).
- De-vigged bookmaker probabilities (`book_p_*`) come from removing the
  overround from decimal odds (proportional method; Shin implemented and
  validated). `odds_*` are the raw decimal odds plus source.
- Blend: `p_blend = w * CatBoost + (1 − w) * Dixon-Coles`, `w = 0.35`.
- Scoreline grid: 15×15 matrix, rows = home goals, columns = away goals,
  normalized to sum to 1; flat list is row-major (`h * 15 + a` indexes the
  cell). The H/D/A marginals of Dixon-Coles are the sums of the grid cells
  (home win = cells with home goals > away goals, draw = diagonal, away =
  complement). The blended H/D/A probabilities are computed from those
  marginals, so **the grid and the blend are consistent by construction**
  (blend DC component = grid marginals; no rescaling was needed or done).

## Models

- Dixon-Coles pickle: penaltyblog goal model with time-decay weights
  (`xi = 0.001`); league-average attack/defence fallback for unseen teams.
- CatBoost binary: MultiClass over `[home, away]` categoricals +
  numeric features, trained on chronological features from
  `src/features.py` (Elo, pi-rating, form, rest, promoted flags; no odds, no
  within-match stats).

## Adding fixtures / re-running live predictions

```bash
.venv/bin/python -m src.export_website     # refits live models, re-exports artefacts
```

Future fixture sets: drop the new season into `src/config.LEAGUES`, refresh
`data/raw/`, and re-run; the live pipeline refits from the full completed
history each time.
