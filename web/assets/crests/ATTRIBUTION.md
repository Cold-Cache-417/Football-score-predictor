# Club crest provenance

These crest files are local copies of the assets already used by the project under `web/public/crests/`. They are included only to make this isolated, non-commercial design prototype feel like a real football product.

Calibra is not affiliated with La Liga or any club. No crest is presented as licensed brand artwork. Several files are used under Wikipedia fair-use rationales; check the source page before reusing them outside this prototype.
