Calibration: does 70% mean 70%?

A forecast that says 70% should happen about seven times in ten. Each point groups predictions into a band: across the bottom is what the model said, up the side is what actually happened. The dashed line is a perfectly calibrated forecaster.

What RPS and log loss actually measure

RPS (ranked probability score) scores the full home/draw/away distribution, so it rewards confidence only when the confidence is earned. Lower is better; a coin-flip forecaster scores about 0.24 on this data, Calibra about 0.19 and the bookmaker about 0.189.

Log loss punishes confident mistakes hard. Lower is better. Both are computed on the same held-out matches shown above, with the same code used on the live record.
